## Distribution boundary

The Sharp/libvips platform packages are unmodified third-party registry
dependencies. Some are inactive on Linux x64; all remain independently
classified and disclosed in the dependency inventory and SBOM. Their source
and binaries are not vendored as Gryloo-authored code. The reference
application's own code remains AGPL-3.0-only.

Any future distributable artifact, container, desktop package or deployment
bundle that embeds or conveys a Sharp/libvips binary requires a separate
release-compliance gate before publication. That gate must verify all
applicable notices, corresponding-source availability and user
replacement/relink requirements. BUILD-002 dependency-governance evidence
does not certify compliance for a future binary distribution.
