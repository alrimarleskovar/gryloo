# BUILD-013 fixed fee ceilings

The prior compiler copied the pinned `getL1FeeUpperBound(8192)` estimate for all remaining calls into `Manifest.feeBudgets.maximumAmount`. A subsequent positive change therefore exceeded the owner's budget even when every other public gate passed. Re-simulation also generated a fresh budget and compared it to the original, coupling accepted authority to the original instantaneous estimate.

New simulations keep `LendingReview.l1FeeUpperBound` as the pinned, current aggregate oracle estimate. The existing Manifest and policy `feeBudgets` bind a maximum of **2 × that estimate**. Their `gasBudgets` bind the total maximum: the sum of reviewed call gas limits times the reviewed gas-price ceiling, plus the maximum L1 fee. The existing Review commitment and artifact chain bind these maximums. No contract schema or format version changes; historical Reviews retain their original budgets and commitments.

The deterministic 2× multiplier follows the existing Supply/composition gas-price policy (`packages/reference-compiler/src/supply.ts` and `lending-composition.ts`). It allows up to 100% movement of the current L1 estimate during the unchanged 120-second Review window. The existing 8,192-byte envelope-size bound and 1.5× simulated gas limits remain unchanged. This is disclosed finite headroom, not a prediction or guarantee that fees stay within it. The full maximum must be funded, and a larger estimate fails closed. The two observed increases of about 1.2% and 7.5% motivate separating estimate from authority; they are not used to tune a timing-dependent margin.

Review, preparation, and handoff reuse the accepted L1 ceiling rather than applying the multiplier again. Reconciled L1 costs reduce the remaining root L1 allowance. Each release repeats the full required sequential simulation and a final pinned L1 oracle read. An estimate exceeding the accepted or remaining root L1 maximum fails with `LENDING_FINAL_L1_FEE_BUDGET_CHANGED`. The existing root network budget also limits already consumed costs plus the remaining maximum network cost. Reconciliation compares actual aggregate fees against the Manifest maximums.

The UI distinguishes the current pinned L1 estimate, maximum owner-approved L1 fee, and maximum total network fee. Accepting Review fixes these values; rechecks do not save or enlarge them. A new explicit Simulate and Review is required for higher authority, while continuation still cannot exceed the original root budget.

Targeted tests cover unchanged, increased-below-maximum, exactly-at-maximum and above-maximum final fees; fee increases during the full re-simulation; cumulative root network/L1 limits; and immutable accepted ceilings at preparation and blocked handoff. Every tested full sequence still has 47 calls, `validation=true`, and no overrides. Existing composition, predecessor, recovery, funding, health, principal, minimum-output and duplicate tests remain mandatory.

The PUBLIC_TESTNET runtime uses only Alchemy Base Sepolia with `GRYLOO_ALCHEMY_API_KEY` in an environment-derived request header. Missing credentials fail closed; the MOCKED loopback harness remains unchanged. The historical BUILD-012 source journals and read-only transcripts are immutable.
