## Evidence boundary

The public-recording server path requires `GRYLOO_PUBLIC_TESTNET=record`, a development server and an absolute `GRYLOO_PUBLIC_TESTNET_JOURNAL`. Normal CI and production builds cannot send a public transaction. The server only constructs artifacts and reads public state; an injected EIP-1193 wallet performs the actual submission after user confirmation. The attempt is journaled before each send, hash before receipt, and recovery never silently resubmits. Approval success alone is not swap completion.
